CSS PHASE 3

CSS Units

Learn how different CSS units control size, spacing and responsive layouts.

01

px — Pixel

Pixel is a fixed-size CSS unit.

300px Width
02

% — Percentage

Percentage is calculated relative to the parent size.

70% Width
03

em — Relative Font Unit

em is relative to the font size of its parent.

1.5em Text
04

rem — Root Relative Unit

rem is relative to the root html font-size.

2rem Text
05

vw — Viewport Width

vw is relative to the width of the viewport.

40vw Width
06

vh — Viewport Height

vh is relative to the height of the viewport.

20vh Height
07

vmin — Smaller Viewport Dimension

vmin uses the smaller value between viewport width and height.

20vmin
08

vmax — Larger Viewport Dimension

vmax uses the larger value between viewport width and height.

20vmax
09

ch — Character Width

ch is based on the width of the "0" character.

This paragraph uses 45ch width to keep the text readable.

10

ex — X-Height Unit

ex is based on the x-height of the current font.

3ex Font Size
11

cm — Centimeter

cm represents centimeters.

5cm Width
12

mm — Millimeter

mm represents millimeters.

50mm Width
13

in — Inch

in represents inches.

2in Width
14

pt / pc — Typography Units

pt means point and pc means pica.

This text uses 18pt.

This text uses 2pc.

Quick Revision

px → Fixed size % → Parent relative em → Parent font relative rem → Root font relative vw → Viewport width vh → Viewport height vmin → Smaller viewport side vmax → Larger viewport side
