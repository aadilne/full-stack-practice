Topic 1: Function Type Annotations
Function type annotation batata hai ki function ke parameters aur return value ka type kya hoga.

Topic 2: Parameter Types
Parameters wo values hain jo function ko input mein milti hain. TypeScript mein har parameter ka type define kar sakte hain.

Topic 3: Return Types
Return type batata hai ki function kis type ki value return karega. Return type : number, : string ya koi aur type ho sakta hai.

Topic 4: Optional Parameters
Parameter ke baad ? lagane se wo optional ho jata hai. Function ko call karte waqt use dena zaroori nahi hota.

Topic 5: Default Parameters
Parameter ki default value set kar sakte hain. Agar argument pass nahi kiya, to default value use hogi.

Topic 6: Rest Parameters
Rest parameter ... se likha jata hai aur multiple arguments ko ek array mein collect karta hai.

Topic 7: Arrow Functions
Arrow function likhne ka short syntax hai: (parameters) => expression.

Topic 8: Function Expressions
Function ko variable mein store karna function expression kehlata hai.

Topic 9: Function Type Definitions
Function type define karke specify kar sakte hain ki function ke parameters aur return type kya honge.

Topic 10: Callback Function Types
Callback ek function hota hai jise doosre function ko argument ke roop mein pass kiya jata hai.

Topic 11: Function Overloads
Function overloads se ek hi function ke liye multiple supported calling signatures define kar sakte hain.

Topic 12: Void Return Type
void ka use un functions ke liye hota hai jo koi useful value return nahi karte.

Topic 13: Never Return Type
never un functions ke liye hota hai jo normally complete nahi hote, jaise hamesha error throw karne wala function.

Topic 14: Best Practices for Functions
- Parameters aur return types ko clear rakho.
- Function ka naam uske kaam ke hisaab se rakho.
- Ek function ko ek clear task do.
- any ka unnecessary use mat karo.
- Optional aur default parameters ko sahi tarah use karo.
